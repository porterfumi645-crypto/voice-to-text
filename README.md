# 听语 · 智能语音转文字

单文件网页应用（`index.html`），支持上传音视频或麦克风实时录音，生成带时间戳的逐字稿、智能纪要，并支持搜索、翻译、纠错和导出 TXT / SRT。

## 两种识别方式（在页面右上角「识别设置」中切换）

- **云端极速识别（默认）**：填入自己的 OpenAI 兼容语音识别接口的 API Key（推荐 Groq 的 whisper-large-v3-turbo；国内网络可用硅基流动）。流程：
  1. MP3 扫描帧表、WAV 读取文件头，不整体解码；
  2. 按并行路数均分时间段，在边界附近的静音处切开；
  3. 多核并行解码为 16kHz 单声道，并用浏览器内置的 WebCodecs 压缩成 Opus（体积约为 WAV 的 1/15）；
  4. 多路并行上传识别（默认 16 路，最多 32 路），结果边返回边显示。

  1 小时的录音在本地只需几秒完成解码和压缩，上传约 11MB，整体通常在 1 分钟内完成；实际耗时取决于网络上传速度和服务商的处理速度与限流额度。
- **本地识别（离线，较慢）**：在浏览器内运行 Whisper 模型（transformers.js），免费，音频不离开本机，速度取决于电脑性能。

可选开启大模型（同样是 OpenAI 兼容接口），用于生成纪要、翻译和 AI 纠错；不开启时纪要由本地规则提取。

API Key 只保存在用户自己浏览器的 localStorage 中，由浏览器直接发送给所选服务商，不会写进网页代码。
