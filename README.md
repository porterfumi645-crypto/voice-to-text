# 听语 · 智能语音转文字

单文件网页应用（`index.html`），支持上传音视频或麦克风实时录音，生成带时间戳的逐字稿、智能纪要，并支持搜索、翻译、纠错和导出 TXT / SRT。

## 两种识别方式（在页面右上角「识别设置」中切换）

- **本地识别**：在浏览器内运行 Whisper 模型（transformers.js），免费，音频不离开本机。首次使用需下载模型（Tiny 约 40MB / Base 约 80MB / Small 约 250MB），有显卡（WebGPU）时更快。
- **云端 API**：填入自己的 OpenAI 兼容语音识别接口（Groq、OpenAI、硅基流动等）的 API Key，长文件会分片并行上传识别，几个小时的录音通常几分钟内完成。

可选开启大模型（同样是 OpenAI 兼容接口），用于生成纪要、翻译和 AI 纠错；不开启时纪要由本地规则提取。

API Key 只保存在用户自己浏览器的 localStorage 中，由浏览器直接发送给所选服务商。

## 大文件

MP3 和 WAV 按段解码，数小时的文件也不会占满内存；其他格式由浏览器整体解码，受浏览器支持的格式和内存限制。
