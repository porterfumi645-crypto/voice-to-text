识别方式

要达到“1 小时录音 1 分钟内识别完”，推荐使用 Groq（Whisper large-v3-turbo，目前最快的公开语音识别服务）：在 console.groq.com/keys 注册并创建 API Key，粘贴到下方。 国内网络无法直连 Groq 时，可选择硅基流动（cloud.siliconflow.cn）。

并行越多越快。服务商的免费额度通常有每分钟请求数和每小时音频时长的限制，超出后会被限流；处理几个小时的录音建议升级到付费档位。

不开启时，纪要由本地规则提取（较简单），翻译不可用，纠错只检查常见错别字。

API Key 只保存在当前浏览器里，识别时由浏览器直接发送给你选择的服务商，不经过任何中间服务器。
